# @atomicfi/transact-react-native

React Native bridge for the Transact SDK

See our [documentation](https://docs.atomicfi.com/reference/transact-sdk#libraries__react-native) for additional information.

## Contributing

Atomic's SDK team maintains this SDK and makes all changes to its code. To report a bug, ask a question or request a feature, open a [GitHub issue](https://github.com/atomicfi/atomic-transact-react-native/issues/new); for a bug, also tell your Atomic account manager. See [CONTRIBUTING.md](CONTRIBUTING.md) for what to include, and [AGENTS.md](AGENTS.md) if you use an AI coding agent.
